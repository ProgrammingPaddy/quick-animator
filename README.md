# Quick Animator

Low-friction, code-based motion graphics for video. A friendlier take on Motion Canvas: a timeline,
a live preview, an object tree, and a code pane that are all views of the same JavaScript, so an
animation can be made by hand or generated by a coding agent.

Status: checkpoint 1, the loop, first slice. See `docs/checkpoints.md`. Open `examples/first`
from the app to try it, and `docs/animation-rules.md` to write a scene.

```
npm install
npm run dev
```
