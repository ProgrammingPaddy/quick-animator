# Quick Animator

Low-friction, code-based motion graphics for video. A friendlier take on Motion Canvas: a timeline,
a live preview, an object tree, and a code pane that are all views of the same JavaScript, so an
animation can be made by hand or generated by a coding agent.

Status: checkpoint 1, the loop, is closed; checkpoint 2, export and headless, first slice. See
`docs/checkpoints.md`. Open `examples/first` from the app to try it, `docs/animation-rules.md`
to write a scene, and `docs/render.md` to render one from the terminal.

```
npm install
npm run dev
```
