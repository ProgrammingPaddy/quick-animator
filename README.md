# Quick Animator

Motion graphics for video, made in code and by hand at once.

A scene is one plain JavaScript file. The preview, the timeline, the object list, and the code
editor are all views of that file: drag an object, trim a clip, or type a line, and the others
follow. Because the file is the truth, an animation can be written by hand, built in the panes,
or generated by a coding agent, and edited any of those ways afterward.

## What it does

- Shapes, text, groups, and masks, drawn in order as layers.
- Animations as short statements: move, rotate, resize, fade, follow a path, morph.
- A timeline of clips to retime, trim, and cut.
- Cameras that frame the scene, move through it, and cut across it.
- Presets for common animations, and your own.
- Export to video or an image sequence, with or without transparency.
